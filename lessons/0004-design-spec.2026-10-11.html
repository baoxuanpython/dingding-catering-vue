📝 实现要点

  1. CSS 变量实现主题
    使用 CSS 自定义属性（变量）定义颜色，切换主题时只需修改根元素的变量值。
  2. localStorage 持久化
    用户选择主题后存入 localStorage，页面加载时读取。
  3. 系统主题检测
    使用 window.matchMedia('(prefers-color-scheme: dark)') 检测系统主题。
  4. Element Plus 主题适配
    Element Plus 支持 CSS 变量主题，需要覆盖默认变量。
  5. 侧边栏折叠状态管理
    使用 Pinia 存储侧边栏折叠状态，避免组件重新渲染时丢失。
