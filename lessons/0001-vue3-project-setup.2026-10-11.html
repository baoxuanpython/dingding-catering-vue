📚 前置知识：前端工具链扫盲

后端 vs 前端项目对比

概念 后端（你熟悉的） 前端（要学的）
依赖管理 Maven / Gradle (pom.xml) npm / yarn / pnpm (package.json)
构建工具 Maven 编译打包 Vite / Webpack
开发服务器 Spring Boot 内嵌 Tomcat Vite Dev Server (热更新)
项目入口 main() 方法 index.html → main.ts
运行环境 JVM 浏览器
💡 后端开发者类比

package.json 就像你的 pom.xml，记录项目依赖和脚本命令。

Vite 就像 Spring Boot 的开发模式，改代码自动刷新，但速度快 10 倍。

node_modules 就像 Maven 的本地仓库，但放在项目目录下。

核心概念解释

  • npm：Node.js 的包管理器，类似 Maven
  • Vite：下一代前端构建工具，极速启动
  • TypeScript：JavaScript 的超集，加了类型系统
  • Vue 3：渐进式 JavaScript 框架

🚀 实战：创建项目

第一步：检查环境

# 检查 Node.js 版本（需要 18+）
node -v

# 检查 npm 版本
npm -v
⚠️ 如果没安装 Node.js

去 nodejs.org 下载 LTS 版本（长期支持版），推荐 v20+。

第二步：用 create-vue 脚手架创建项目

# 在项目根目录执行
npm create vite@latest . -- --template vue-ts
📝 命令解析
  • npm create：使用 npm 的创建项目功能
  • vite@latest：使用最新版的 Vite 脚手架
  • .：在当前目录创建（不创建子文件夹）
  • --template vue-ts：使用 Vue + TypeScript 模板

第三步：安装依赖

npm install
📦 这步做了什么？

类似 mvn install，会下载 package.json 里声明的所有依赖到 node_modules 目录。

第四步：启动开发服务器

npm run dev
✅ 成功标志

终端会显示类似这样的信息：

VITE v5.0.0 ready in 200 ms

➜ Local: http://localhost:5173/
➜ Network: use --host to expose

在浏览器打开 http://localhost:5173 就能看到 Vue 的欢迎页面！

📁 项目结构解析

创建完成后，你的项目目录长这样：

dingding-catering-vue/
├── node_modules/ # 依赖包（类似 Maven 仓库，不用管）
├── public/ # 静态资源（图片、favicon 等）
│ └── vite.svg
├── src/ # 源代码目录（你主要工作的地方）
│ ├── assets/ # 组件级别的静态资源
│ │ └── vue.svg
│ ├── components/ # Vue 组件（类似后端的 Service/Controller）
│ │ └── HelloWorld.vue
│ ├── App.vue # 根组件（类似 Spring 的主配置类）
│ ├── main.ts # 入口文件（类似 main() 方法）
│ └── style.css # 全局样式
├── index.html # HTML 入口（类似后端的 index.jsp）
├── package.json # 项目配置（类似 pom.xml）
├── tsconfig.json # TypeScript 配置
├── vite.config.ts # Vite 构建配置
└── package-lock.json # 依赖锁定文件（类似 pom.xml 的锁定版本）
💡 核心文件类比

main.ts = 你的 Application.java，程序入口

App.vue = 你的主配置类，所有组件的根

components/ = 你的 Service/Controller 层，每个组件是一个功能模块

vite.config.ts = 你的 application.yml，构建和开发服务器配置

🔍 核心文件解读

package.json

{
  "name": "dingding-catering-vue",
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite", # 开发服务器（开发时用这个）
    "build": "vue-tsc -b && vite build", # 生产构建
    "preview": "vite preview" # 预览构建结果
  },
  "dependencies": {
    "vue": "^3.5.0" # 运行时依赖（类似 pom.xml 的 dependencies）
  },
  "devDependencies": {
    "typescript": "~5.6.0", # 开发时依赖（类似 pom.xml 的 test scope）
    "vite": "^5.4.0",
    "@vitejs/plugin-vue": "^5.1.0",
    "vue-tsc": "^2.1.0"
  }
}

main.ts - 入口文件

import { createApp } from 'vue'
import App from './App.vue'
import './style.css'

// 创建 Vue 应用实例，挂载到 #app 元素上
createApp(App).mount('#app')
📝 类比理解

这就像 Spring Boot 的：

@SpringBootApplication
public class Application {
  public static void main(String[] args) {
    SpringApplication.run(Application.class, args);
  }
}

都是"启动框架，加载配置，开始监听"的作用。

App.vue - 根组件

<!-- Vue 组件是 .vue 文件，包含三部分 -->

<!-- 1. 模板：HTML 结构 -->
<template>
  <div>
    <h1>{{ message }}</h1>
  </div>
</template>

<!-- 2. 脚本：逻辑代码 -->
<script setup lang="ts">
import { ref } from 'vue'
const message = ref('Hello Vue 3!')
</script>

<!-- 3. 样式：CSS -->
<style scoped>
h1 {
  color: #409EFF;
}
</style>
⚠️ Vue 组件的三要素

每个 .vue 文件都包含三个部分：

  • <template>：视图层（类似 JSP/Thymeleaf 的 HTML 部分）
  • <script>：逻辑层（类似 Controller + Service）
  • <style>：样式层（CSS，后端没有对应概念）

scoped 关键字表示样式只在这个组件内生效（类似 CSS Modules）。
