# MISSION: 从零搭建叮叮餐饮后台管理系统

## 背景
我是一名后端开发者，现在需要独立开发一个外卖后台管理系统的前端部分。之前前端经验很少，需要从零基础开始学习现代前端开发。

## 目标
使用 **Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router** 技术栈，从零搭建一个完整的后台管理系统。

## 业务场景
- **项目名称**：叮叮餐饮外卖后台管理系统
- **用户**：商家（用于管理订单、菜品、套餐、员工等）
- **后端**：我自己开发（全栈项目）
- **接口文档**：YApi 生成的管理端接口文档

## 核心功能模块
1. 登录/退出
2. 工作台（今日运营数据）
3. 订单管理（接单、拒单、派送、完成、取消）
4. 菜品管理（CRUD、起售/停售）
5. 套餐管理（CRUD、起售/停售）
6. 分类管理（CRUD）
7. 员工管理（CRUD、状态管理）
8. 数据统计（营业额、订单、用户统计）
9. 店铺操作（营业状态）

## 学习要求
- 混合学习模式：先讲原理，立刻动手验证
- 每个概念都要有可运行的代码
- 用后端熟悉的概念类比前端概念
- 以真实业务模块为载体学习

## 成功标准
- 能独立开发新的后台管理页面
- 理解 Vue 3 核心概念（组件、响应式、生命周期）
- 掌握前后端交互（API 调用、状态管理）
- 能独立完成项目部署
