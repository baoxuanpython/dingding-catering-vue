安装 Element Plus + Vue Router + Pinia

📅 2026-10-11 🏷️ #ElementPlus #VueRouter #Pinia #Axios ⏱️ 预计 20 分钟

🎯 本课目标

为项目安装所有核心依赖，理解每个库的作用，并完成基础配置。

完成后你将获得：
  • Element Plus UI 组件库（后台管理页面的"零件库"）
  • Vue Router 路由系统（页面导航）
  • Pinia 状态管理（全局数据管理）
  • Axios HTTP 客户端（前后端通信）

📚 依赖清单：它们是什么？

库 后端类比 作用
Element Plus Bootstrap / Ant Design 现成的 UI 组件（按钮、表格、表单、弹窗等）
Vue Router Spring MVC 的 @RequestMapping URL 路径与页面的映射关系
Pinia Spring 的 @Service + 内存缓存 全局状态管理（用户信息、菜单权限等）
Axios RestTemplate / HttpClient 发送 HTTP 请求调用后端 API
💡 整体架构类比

想象你在开发一个 Spring Boot 项目：

  • Element Plus = Thymeleaf 模板 + Bootstrap 样式（视图层）
  • Vue Router = @Controller + @RequestMapping（路由层）
  • Pinia = @Service + @Component（业务逻辑层）
  • Axios = RestTemplate（HTTP 客户端）

只不过这些在前端都是独立的库，需要手动安装和配置。

🚀 实战：安装依赖

第一步：安装 Element Plus

$ npm install element-plus @element-plus/icons-vue
📦 说明
  • element-plus：UI 组件库本体
  • @element-plus/icons-vue：图标库（后台管理需要大量图标）

第二步：安装 Vue Router

$ npm install vue-router@4
📦 说明

@4 表示安装 Vue Router 4.x 版本，这是配合 Vue 3 的版本。

第三步：安装 Pinia

$ npm install pinia

第四步：安装 Axios

$ npm install axios

⚙️ 配置：让它们协同工作

第一步：在 main.ts 中注册所有插件

打开 src/main.ts，修改为：

import { createApp } from 'vue'
import { createPinia } from 'pinia'
import ElementPlus from 'element-plus'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import 'element-plus/dist/index.css'
import App from './App.vue'
import router from './router'

// 创建 Vue 应用实例
const app = createApp(App)

// 注册 Pinia（全局状态管理）
app.use(createPinia())

// 注册 Vue Router（路由系统）
app.use(router)

// 注册 Element Plus（UI 组件库）
app.use(ElementPlus)

// 注册所有 Element Plus 图标
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

// 挂载应用到 #app 元素
app.mount('#app')
📝 类比理解

这就像 Spring Boot 的 @Configuration 类，把所有 Bean 注册到容器中：

@Configuration
public class AppConfig {
  @Bean
  public Pinia pinia() { return new Pinia(); }

  @Bean
  public Router router() { return new Router(); }

  @Bean
  public ElementPlus elementPlus() { return new ElementPlus(); }
}

只不过前端是用 app.use() 来注册插件。

第二步：创建路由配置

创建 src/router/index.ts：

import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/',
    redirect: '/login'
  },
  {
    path: '/login',
    name: 'Login',
    component: () => import('../views/Login.vue')
  },
  {
    path: '/dashboard',
    name: 'Dashboard',
    component: () => import('../views/Dashboard.vue')
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
📝 路由配置类比

这就像 Spring MVC 的路由配置：

@Controller
public class PageController {

  @GetMapping("/")
  public String index() {
    return "redirect:/login";
  }

  @GetMapping("/login")
  public String login() {
    return "login"; // 返回 login 页面
  }

  @GetMapping("/dashboard")
  public String dashboard() {
    return "dashboard"; // 返回 dashboard 页面
  }
}

前端的 component: () => import(...) 是懒加载，只有访问该路由时才加载对应组件，类似后端的按需加载。

第四步：修改 App.vue

修改 src/App.vue 为路由出口：

<template>
  <router-view />
</template>

<script setup lang="ts">
// App.vue 现在只是一个路由出口
// 实际页面由 router 决定渲染哪个组件
</script>
📝 router-view 是什么？

<router-view /> 是一个占位符，Vue Router 会根据当前 URL 自动渲染对应的组件。

类比后端的 ViewResolver：根据 Controller 返回的视图名，找到对应的模板文件渲染。

dingding-catering-vue/
├── src/
│ ├── router/ # 路由配置（新增）
│ │ └── index.ts
│ ├── views/ # 页面组件（新增）
│ │ ├── Login.vue # 登录页
│ │ └── Dashboard.vue # 仪表盘
│ ├── components/ # 可复用组件
│ ├── App.vue # 根组件（已修改）
│ └── main.ts # 入口文件（已修改）
├── package.json
└── index.html
⚠️ 目录规范说明
  • views/：页面级组件（与路由对应），通常是一个完整的页面
  • components/：可复用组件（如表格、表单组件），可在多个页面中使用

类比后端：views/ 像 Controller 返回的完整页面，components/ 像 Thymeleaf 的 fragment。

🎓 小测验

  1. Q1: app.use() 的作用是什么？
    点击查看答案

    注册 Vue 插件（如 Element Plus、Vue Router、Pinia），类似 Spring 的 Bean 注册。

  2. Q2: 路由配置中的 () => import(...) 是什么？
    点击查看答案

    动态导入（懒加载），只有访问该路由时才加载对应组件，减少首屏加载时间。

  3. Q3: <router-view /> 的作用是什么？
    点击查看答案

    路由出口，Vue Router 会根据当前 URL 自动渲染对应的组件。
