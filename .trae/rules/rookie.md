# 用户画像与教学规则

## 基本信息
- **角色**：全栈开发者（后端经验丰富，前端基础薄弱）
- **前端水平**：新手级别，之前做前端太少
- **后端能力**：熟练，能独立完成后端开发
- **项目**：叮叮餐饮外卖后台管理系统（商家端）

## 技术栈选择
```
Vue 3 + TypeScript + Vite + Element Plus + Pinia + Vue Router
```

### 技术选型理由
- **Vue 3**：渐进式框架，学习曲线平缓，适合后端开发者
- **TypeScript**：类型系统与后端语言相似，降低认知负担
- **Vite**：现代构建工具，速度快，配置简单
- **Element Plus**：成熟的后台管理 UI 组件库，开箱即用
- **Pinia**：轻量状态管理，比 Vuex 更简单直观
- **Vue Router**：官方路由方案，生态完善

## 学习偏好
- **学习方式**：C 模式（混合模式）- 先讲原理，立刻用代码验证
- **教学节奏**：每个概念先讲解，然后动手实践
- **项目驱动**：以实际业务模块为载体学习（订单管理、菜品管理等）

## 后端接口信息
- **接口文档**：YApi 生成的 HTML 文档
- **接口路径**：`./叮叮餐饮接口文档/叮叮餐饮-管理端接口.html`
- **主要模块**：
  - 分类管理（CRUD）
  - 员工管理（登录、CRUD、状态管理）
  - 套餐管理（CRUD、起售/停售）
  - 菜品管理（CRUD、起售/停售）
  - 订单管理（接单、拒单、派送、完成、取消）
  - 数据统计（营业额、订单、用户统计）
  - 工作台（今日运营数据）
  - 店铺操作（营业状态）

## 教学规则
1. **避免前端黑话**：解释所有前端专有名词
2. **对比后端概念**：用后端熟悉的概念类比前端概念
3. **代码优先**：每个概念都要有可运行的代码示例
4. **渐进式**：从最简单的项目结构开始，逐步添加复杂度
5. **实战导向**：所有练习都基于真实的业务场景

## 项目目标
从零搭建一个完整的后台管理系统，包含：
- 登录/退出功能
- 主布局（侧边栏、顶部导航、内容区）
- 各业务模块的 CRUD 页面
- 数据统计图表
- 权限控制（路由守卫）
