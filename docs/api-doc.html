HTTP 状态码说明

HTTP 状态码 含义 前端处理建议
200 请求成功 正常处理响应数据
400 参数校验失败 提示用户检查输入
401 认证失败（未登录/令牌过期/密码错误等） 跳转登录页
403 权限不足 提示用户无权操作
409 资源冲突（数据已存在/不允许删除等） 提示用户具体冲突原因
422 业务规则不满足 提示用户具体业务错误
500 服务器内部错误 提示系统异常，联系管理员

统一响应格式

JSON 
{
  "code": 1,
  "msg": "操作成功",
  "data": {}
}

code: 状态码，1=成功，其他=失败
msg: 提示信息
data: 响应数据，类型因接口而异

统一分页响应格式

JSON 
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "total": 100,
    "records": []
  }
}

total: 总记录数
records: 当前页数据列表

字段类型对照表

TypeScript 类型 Java 类型 数据库类型 说明
number Long bigint 64位整数
number Integer int 32位整数
number BigDecimal decimal(10,2) 金额（两位小数）
string String varchar 字符串
string LocalDateTime datetime 日期时间（ISO 8601）
string LocalDate date 日期（yyyy-MM-dd）
array List<T> - 数组/列表

订单状态说明

状态值 含义 说明
1 待付款 用户已下单，等待支付
2 待确认 用户已支付，等待商家接单
3 已确认 商家已接单，等待派送
4 派送中 订单正在派送
5 已完成 订单已完成
